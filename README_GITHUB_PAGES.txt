DayMark v5.0 - GitHub Pages 배포용

업로드할 파일:
- index.html
- style.css
- script.js
- .nojekyll

GitHub Pages 설정:
1. GitHub에서 새 Repository 생성 (예: daymark)
2. 위 4개 파일을 Repository 최상위(root)에 업로드
3. Settings > Pages
4. Source: Deploy from a branch
5. Branch: main / Folder: /(root)
6. Save
7. 배포 완료 후 표시되는 사이트 주소로 접속

예상 주소:
https://사용자이름.github.io/daymark/

참고:
- 일정/카테고리/설정 데이터는 각 브라우저의 localStorage에 저장됩니다.
- 같은 URL을 PC와 휴대폰에서 열어도 데이터는 자동 동기화되지 않습니다.
- Pretendard는 CDN을 사용하므로 인터넷 연결 시 적용됩니다.
